# NHANES Blood Pressure Analysis

My first data science project, exploring how **average systolic blood pressure differs across age groups** using NHANES 2015–2016 data.

## What I Did

- Grouped participants by age using **Pandas**.
- Calculated the **mean, median, standard deviation, and count** for each group.
- Created a **bar chart** using Seaborn and Matplotlib.
- Calculated **Pearson's correlation** between age and systolic blood pressure.

## Key Finding

Average systolic blood pressure generally increased across older age groups. Pearson's correlation coefficient was approximately **0.469**, indicating a moderate positive relationship in this dataset.

## Tools

Python · Pandas · Seaborn · Matplotlib · Jupyter Notebook
